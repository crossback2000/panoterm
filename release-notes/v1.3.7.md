## 새 기능

- **파일 탐색기 (📁, Ctrl+Shift+E)**: 서버 폴더를 둘러보고 파일을 열 수 있어요. 지금 tmux 창이 있는 폴더에서 시작해서 Claude가 방금 고친 파일을 바로 찾을 수 있어요. 파일을 길게 누르면 경로를 터미널에 넣거나 복사할 수 있어요.
- **코드 뷰어**: 줄 번호와 색 구분(Kotlin, Go, JS/TS, Python, 셸, `.env`, YAML, JSON, Markdown, Dockerfile 등)을 붙여 화면 폭에 맞춰 보여 줘요. 찾기, 글자 크기 조절, 가로 스크롤 전환이 되고, `.env` 값은 기본으로 가려져요.
- **간단 편집기**: ✎를 눌러 고치고 저장(Ctrl+S)해요. 연 뒤에 서버에서 파일이 바뀌었으면 덮어쓰기 전에 물어보고, 저장 중 연결이 끊겨도 파일이 반쯤 쓰인 채로 남지 않아요. 파일 권한도 그대로 유지돼요.
- **작업 상태 탭**: 세션이나 tmux 창이 여러 개면 상단 막대 아래에 탭이 생겨요. 파랑(깜빡임)은 작업 중, 주황은 승인(1/2/3)이나 입력 대기, 초록은 쉬는 중이에요. 탭을 한 번 누르면 그곳으로 넘어가요. 설정 → "작업 상태 탭"에서 끌 수 있어요.
