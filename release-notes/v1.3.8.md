## 고친 것

- **한글을 치다가 휴대폰 키보드의 ⌫가 안 먹던 문제를 고쳤어요.** 이제 조합 중인 글자는 자모 단위로(한 → 하 → ㅎ) 지워지고, 이어서 앞 글자가 지워져요. 키 막대의 ⌫만 되던 문제예요.
- **K380에서 영어가 안 쳐지고 한글만 나오던 문제를 고쳤어요.** 휴대폰 키보드와 앱이 둘 다 Shift+Space로 한/영을 바꾸다 엇갈렸어요. 이제 한/영은 휴대폰 키보드 한 곳에서만 관리해요.
- **작업 상태 탭이나 세션 메뉴로 세션을 바꾸면 K380 입력이 안 먹던 문제를 고쳤어요.** 이때 휴대폰 키보드로 친 글자가 화면에 안 보이는 이전 세션으로 갈 수 있던 문제도 같이 고쳤어요.

## 바뀐 것

- 휴대폰 키보드 입력 방식을 새로 만들었어요. 키보드가 보통 입력칸처럼 글자를 조합하고, 앱은 확정된 글자만 서버로 보내요. 삼성 키보드·Gboard뿐 아니라 천지인, 일본어 입력도 같은 방식으로 동작해요.
- 앱 자체 한글 조합(K380용)은 기본으로 꺼졌어요. 휴대폰 키보드가 하드웨어 키보드 한글을 못 칠 때만 설정 → "앱에서 한글 조합"을 켜세요. 켜면 상단에 '한'이 보여요.
