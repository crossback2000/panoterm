## 보안

- **터미널 화면에서 링크를 눌러도 앱 안에서 다른 페이지가 열리지 않아요.** 링크는 항상 브라우저로 열리고, `http`/`https` 링크만 열어요. 서버 출력에 섞인 이상한 링크가 앱 안에서 열려 터미널에 입력을 넣는 경로를 막았어요.
- **서버에 올린 사진은 나만 읽을 수 있게 저장해요.** `~/.cache/panoterm` 폴더와 파일 권한을 본인 전용으로 바꿨고, 7일 지난 사진은 다음에 올릴 때 알아서 지워요.
- 자동 업데이트가 받은 파일의 서명을 더 엄격하게(인증서 전체 해시로) 확인해요.
- 내장 Tailscale/SSH 쪽 압축 라이브러리를 보안 패치 버전으로 올렸어요.

## 고친 것

- 앱을 켤 때 받아 둔 업데이트 파일을 검사하느라 잠깐 멈칫하던 걸 없앴어요.
- 업데이트 파일을 이미 받아 둔 경우 다시 받지 않아요. 받다가 실패한 조각 파일도 정리해요.
