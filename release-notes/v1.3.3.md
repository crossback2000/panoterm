## 고친 것

- **스크롤하면 Claude 답변이 겹쳐 보이던 문제를 다시 고쳤어요.** 1.3.2로는 실제 폰에서 다 해결되지 않았어요.
  - 한글 조합 막대(노란 줄), 자동완성 줄, 승인 버튼 줄이 이제 터미널 위에 겹쳐 떠요. 글자를 칠 때마다 터미널 크기가 바뀌고 Claude가 화면 전체를 다시 그리던 일이 없어졌어요.
  - 키보드가 올라오고 내려가는 동안에는 크기를 바꾸지 않고, 멈춘 뒤에 한 번만 바꿔요.
  - 크기가 바뀐 뒤 Claude가 다시 그린 화면과 기록이 겹치면 겹친 줄을 지워요.
- **한글을 치다가 `?`, 띄어쓰기, Enter를 누르면 순서가 뒤바뀌던 문제를 고쳤어요.** "되요?"가 "되?요"로 들어가던 현상이에요. 키 줄 버튼을 누를 때도 마찬가지예요.
