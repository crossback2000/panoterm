## 고친 것

- **화면을 나갔다 들어오면 아래로 스크롤이 안 되던 문제를 고쳤어요.**
  - 터미널이 이제 화면이 아니라 세션에 속해요. 화면을 나가도 터미널은 그대로 살아 있고, 다시 들어오면 보던 상태 그대로 이어져요.
  - 예전에는 다시 들어올 때마다 최근 출력으로 화면을 새로 그렸는데, 이때 Claude Code 전체 화면 모드의 설정(마우스 스크롤 등)이 빠질 수 있었어요.
  - 다시 들어오는 속도도 빨라졌어요.
- **붙여넣기를 쓰기 쉽게 바꿨어요.**
  - 글자를 선택하면 안드로이드 기본 메뉴가 떠요: 복사 / 붙여넣기 / 입력 / 전체 선택.
  - `입력`: 고른 글자를 클립보드를 거치지 않고 바로 입력줄에 넣어요.
  - 빈 곳을 길게 누르면 붙여넣기 메뉴가 떠요.
  - 키보드(Gboard 등)의 클립보드에서 여러 줄을 붙여넣어도 줄마다 실행되지 않고 한 번에 들어가요.
- 화면 그리기 방식을 바꾸면, 열려 있는 세션도 터미널을 다시 열 때 바로 적용돼요.
