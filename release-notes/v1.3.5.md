## 고친 것

- **화면을 나갔다 들어오면 아래로 스크롤이 안 되던 문제를 고쳤어요.**
  - 터미널이 이제 화면이 아니라 세션에 속해요. 화면을 나가도 터미널은 그대로 살아 있고, 다시 들어오면 보던 상태 그대로 이어져요.
  - 예전에는 다시 들어올 때마다 최근 출력으로 화면을 새로 그렸는데, 이때 Claude Code 전체 화면 모드의 설정(마우스 스크롤 등)이 빠질 수 있었어요.
  - 다시 들어오는 속도도 빨라졌어요.
- **붙여넣기를 쓰기 쉽게 바꿨어요.**
  - 글자를 선택하면 안드로이드 기본 메뉴가 떠요: 복사 / 붙여넣기 / 입력 / 전체 선택.
  - `입력`: 고른 글자를 클립보드를 거치지 않고 바로 입력줄에 넣어요.
  - 빈 곳을 길게 누르면 붙여넣기 메뉴가 떠요.
  - 키보드(Gboard 등)의 클립보드에서 여러 줄을 붙여넣어도 줄마다 실행되지 않고 한 번에 들어가요.
- 화면 그리기 방식을 바꾸면, 열려 있는 세션도 터미널을 다시 열 때 바로 적용돼요.
- **휴대폰 상단 상태 표시줄(시계·배터리)이 다시 보여요.** 휴대폰이 밝은 테마일 때 검은 바탕에 검은 아이콘으로 그려져 안 보였어요.
- **터미널 위쪽 아이콘을 직접 고를 수 있어요.** `⋮` → `상단 아이콘 편집`(또는 설정 → 터미널 상단 아이콘 편집). 고르지 않은 건 `⋮` 메뉴에 있어요.
- **한글 조합 중 노란 막대를 없앴어요.** 조합 중인 글자가 커서 자리에 바로 보이고, 화면이 올라가지 않아요.
- **자동완성이 입력 중인 줄 바로 위에 떠요.** 아래에 줄이 생기면서 화면이 밀려 올라가던 문제가 없어졌어요. 반응도 빨라졌어요(대기 시간 단축, 폴더 목록 잠깐 기억).
- **Claude에서 `/`를 쳤을 때 엉뚱한 목록이 나오던 문제를 고쳤어요.** 새 Claude Code의 입력창(`❯`)을 셸로 착각해서 서버 최상위 폴더 목록을 보여주고 있었어요. 이제 Claude가 화면에 띄운 명령 목록을 그대로 쓰고, 내 명령과 스킬도 같이 나와요.
- 아래 키 줄에 같은 키가 두 번 나오지 않게 했어요.
