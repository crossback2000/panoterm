## 새 기능

- **영어를 지원해요.** 기기 언어가 한국어면 한국어, 그 밖에는 영어로 나와요. Android 13 이상에서는 설정 맨 위 **언어**(시스템 설정 따르기 / English / 한국어)나 기기 설정의 앱별 언어에서 바꿀 수 있어요.
- 화면 키 줄 편집에서 키마다 무슨 키인지 설명이 나와요. 예: `⇧Tab` → "Shift+Tab · Claude Code 모드 전환 (자동 수락 / 계획 모드)".

## 버그 수정

- 영어로 치다가 ⌫가 안 먹던 문제를 고쳤어요. 휴대폰 키보드와 하드웨어 키보드 모두 해당돼요.
- 잠깐 신호가 약해지기만 해도 `connection lost (keepalive timeout)`으로 끊기던 문제를 고쳤어요. 이제 연속 3번(약 45~60초) 응답이 없을 때만 끊어요.
- 세션을 6시간 넘게 열어 두면 화면이 꺼진 동안 연결이 끊기던 문제를 고쳤어요.
