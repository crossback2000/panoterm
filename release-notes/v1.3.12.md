## 보안

- Android 17 기준으로 앱을 올렸어요. 처음 실행할 때 **"근처 기기 / 로컬 네트워크" 권한**을 물어봐요. 허용해야 집·회사 같은 Wi-Fi에 있는 서버(192.168.x.x 등)에 SSH로 바로 붙고, Tailscale도 같은 Wi-Fi에서는 직접 연결돼요. 거부해도 Tailscale은 인터넷을 거쳐 그대로 동작해요.
- 백업 파일 암호화를 더 단단하게 바꿨어요. 예전 백업 파일도 그대로 불러올 수 있어요.
- 키 암호·백업 암호 입력칸에서 복사/잘라내기가 막히고, 키보드가 입력 내용을 학습하지 않아요.

## 개선

- 터미널 화면 엔진(xterm.js)을 6.0으로 올렸어요. 스크롤 위치를 보여주는 얇은 막대가 오른쪽 끝에 잠깐 나타나요.
- 설정 → 화면 그리기 방식에서 Canvas가 없어졌어요 (새 엔진에서 빠짐). Canvas를 골라 뒀다면 자동으로 바뀌어요. 자동은 GPU가 있으면 WebGL, 없으면 DOM이에요.
- Jetpack Compose 등 앱 라이브러리와 빌드 도구(NDK r30, Gradle 9.9.2)를 최신으로 올렸어요.
