## 고친 것

- **키보드가 올라올 때 화면이 여러 번 움직이던 문제를 고쳤어요.**
  - 이제 터미널과 키 줄이 키보드와 같은 속도로 함께 부드럽게 올라가고 내려가요.
  - 터미널 크기는 키보드를 열고 닫을 때마다 한 번만 바뀌어요. 서버 쪽 Claude Code도 화면을 한 번만 다시 그려요.
  - 그동안 겹친 스크롤 기록을 지우던 보정 코드는 뺐어요.

## 권장 설정

- **Claude Code는 전체 화면 모드로 쓰세요.** Claude Code 안에서 `/tui fullscreen`을 한 번 입력하면 저장돼요.
  - 기존 방식은 화면 크기가 바뀔 때 스크롤 기록에 같은 내용이 겹쳐 남는 문제가 Claude Code 자체에 있어요.
  - 전체 화면 모드에서는 입력창이 항상 맨 아래에 고정되고, 위로 밀어서 지난 대화를 볼 수 있어요.
