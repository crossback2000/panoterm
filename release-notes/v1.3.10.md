## 새 기능

- **하드웨어 키에 "쓸 때마다 지문 확인" 옵션을 추가했어요.** 키를 만들 때 켜면 접속할 때마다 보안 칩이 직접 지문을 요구해요. 이 키를 쓰는 호스트는 앱 단계 인증을 한 번 더 묻지 않아요. 기본은 꺼져 있어요.

## 보안

- **링크를 열기 전에 실제 주소를 보여줘요.** 터미널의 링크(OSC 8)는 화면 글자와 실제 주소가 다를 수 있어서, 열기 전에 주소를 확인받아요. 그냥 URL 글자는 지금처럼 바로 열려요.
- **포트 포워딩은 30분 동안 연결이 없으면 자동으로 닫혀요.** 폰의 다른 앱도 포워딩된 포트에 접속할 수 있기 때문이에요.
- **"서버에서 클립보드 복사"가 이제 기본으로 꺼져 있어요.** 필요하면 설정에서 켜세요.
- 기기 이전이나 클라우드 백업에 앱 데이터(키, Tailscale 노드 정보 등)가 따라가지 않게 막았어요.
- 앱 잠금을 켜 두면 최근 앱 화면에 터미널 내용이 보이지 않아요. (Android 13 이상)
- 백업을 복원할 때 파일 내용을 더 엄격하게 검사해요.

## 고친 것

- 한글 출력 중에 벨·작업 완료 알림을 놓치던 문제를 고쳤어요.
